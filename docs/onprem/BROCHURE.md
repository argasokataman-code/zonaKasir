# zonaKasir — Kasir Lengkap, Data 100% Milik Anda

> **Satu server, satu toko, satu kepemilikan penuh.**
> Tanpa langganan bulanan, tanpa data di cloud orang lain.

---

## Kenapa On-Premise?

| SaaS (cloud) | **On-Premise (zonaKasir)** |
|---|---|
| Bayar langganan tiap bulan | **Bayar sekali, pakai selamanya** |
| Data tersimpan di server vendor | **Data di server Anda sendiri** |
| Fitur mati kalau telat bayar | **Kasir TIDAK pernah berhenti** |
| Tergantung internet vendor | **Jalan offline di jaringan toko** |

---

## Fitur Kasir Lengkap

**Penjualan & Kasir**
- POS cepat: produk, barcode, shortcut tombol pembayaran
- Struk cetak A5, label produk, printer kasir
- Diskon, voucher, pajak (PPN), catatan transaksi
- Pembayaran tunai & non-tunai (QRIS, transfer, kartu)

**Produk & Stok**
- SKU, barcode, kategori, gambar produk
- Stok masuk/keluar, stok opname, stok awal
- Produk non-stok (jasa/layanan), harga awal, tanggal kedaluwarsa
- Import produk massal dari file

**Keuangan**
- Laporan penjualan, laba, piutang (receivable)
- Hutang supplier (purchasing/pembelian)
- Laci kas (cash drawer), settlement harian
- Laporan kasir lengkap

**Pelanggan & Relasi**
- Manajemen member, voucher/diskon member
- Data supplier, daftar piutang per pelanggan

**Pengaturan**
- Multi-user dengan role & permission
- Meja (untuk resto/kafe), profil toko
- Sesuai kebutuhan tiap jenis usaha

## Kenapa zonaKasir On-Premise Aman?

- **Lisensi per domain** — dikunci ke alamat toko Anda, dibuat khusus
- **Kasir tidak pernah diblokir** — lisensi hanya pengingat, bukan ancaman
- **Update resmi** — setiap pembaruan ditandatangani digital, file palsu ditolak
- **Data penuh di server Anda** — bukan di cloud pihak ketiga

## Cara Kerja

```
┌─────────────────────────────────────────┐
│  Server di toko Anda                    │
│  (bisa PC biasa / mini server)          │
│                                         │
│  zonaKasir  +  database lokal Anda      │
│   kasir jalan offline / intranet        │
└─────────────────────────────────────────┘
```

- Akses lewat browser di HP/PC kasir — tanpa install aplikasi tambahan
- Satu toko = satu server. Gampang dirawat, tanpa biaya cloud bulanan
